# React Ecom Frontend

This project was made to refresh my skills getting back into web development. I picked up HTML, CSS and javaScript again after not using them for over a year. The project is designed to mimic the frontend of an ecommerce store selling digital products.

The product data is stored as json and put into the browser's local storage and then mapped onto Card components and displayed on the Product page. In the future, the user will be able to click on a product title or image to view more details about it.
